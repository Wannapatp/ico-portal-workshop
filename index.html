1Stablecoin และ Programmable Payment ในกระบวนการ ICO
ปัญหา
ต้นทุนการรับชำระค่าจองซื้อและการจ่ายผลตอบแทนผ่านสถาบันการเงิน และยังไม่มีแนวทางที่ชัดเจนในการจ่ายผลตอบแทนเป็น Stablecoin
แนวทางที่เสนอ
  • ใช้ Stablecoin หรือ Programmable Payment ตั้งแต่การจองซื้อผ่าน Smart Contract
  • จ่ายผลตอบแทนและคืนเงินต้นโดยอัตโนมัติ
2KYC Sharing และการยืนยันสถานะผู้ลงทุน
ปัญหา
ผู้ลงทุนต้องเปิดบัญชีใหม่กับ ICO Portal แต่ละราย และต้องพิสูจน์คุณสมบัติผู้ลงทุนซ้ำ
แนวทางที่เสนอ
  • ระบบกลางเพื่อการจองซื้อระหว่าง ICO Portal และ บล.
  • เชื่อข้อมูลการจัดประเภท UHNW/HNW และรายงานผลการขายเป็น Ref.
  • ยกเว้นเพดานร้อยละ 70 สำหรับ Real Estate-backed และ Infra-backed Token
3การยกระดับโครงสร้าง ICO
ปัญหา
ต้นทุนและระยะเวลาการขออนุญาตสูงกว่าการออกหุ้นกู้ และยังไม่จูงใจผู้ลงทุนสถาบัน
แนวทางที่เสนอ
  • Filing Template ข้อกำหนดสิทธิ และ Working Paper มาตรฐาน
  • จัดอันดับความน่าเชื่อถือ Debt-like Token (Optional) และนับเป็น NC/CAR
  • ผลตอบแทนบางส่วนอ้างอิงปัจจัยอื่นนอกจากโครงการได้
4สถานะทางกฎหมายและการใช้โทเคนเป็นหลักประกัน
ปัญหา
กฎหมายยังไม่รับรองให้โทเคนดิจิทัลเพื่อการลงทุนใช้เป็นหลักประกันได้เช่นเดียวกับหลักทรัพย์
แนวทางที่เสนอ
  • แก้ไข พ.ร.ก. สินทรัพย์ดิจิทัลฯ ให้โทเคนเป็นสิทธิที่ใช้เป็นหลักประกันได้ เทียบมาตรา 228/1 และ 228/2
  • กำหนดให้ผู้แทนผู้ถือโทเคนดิจิทัลเป็นผู้รับหลักประกัน
5สิทธิประโยชน์ทางภาษี
ปัญหา
ภาษีมูลค่าเพิ่มซ้ำซ้อนในการออก การเปลี่ยนมือ และการ Redemption ของ Utility Token และยังไม่มีแรงจูงใจทางภาษีสำหรับ Investment Token
แนวทางที่เสนอ
  • ขจัด VAT ซ้ำซ้อน เพื่อสนับสนุน Hybrid Token
  • สิทธิประโยชน์ทางภาษีในลักษณะเดียวกับ SSF, RMF หรือ Thai ESG

  • เพิ่มหรือลดทรัพย์สิน และกู้ยืมเงินได้อย่างยืดหยุ่น
